# Knowing Is Not Telling · project site

A standalone site for the paper, separate from the personal homepage.

## Deploy (GitHub Pages)
1. New repository named **knowing-is-not-telling** (Public).
2. Upload everything in this folder (index.html, images/, favicon files, .nojekyll, robots.txt).
3. Settings → Pages → Deploy from a branch → main / (root) → Save.
4. The site appears at https://ooodddee.github.io/knowing-is-not-telling/

If you use a different repository name, replace `https://ooodddee.github.io/knowing-is-not-telling/` in index.html (canonical and og tags) with the new address.
